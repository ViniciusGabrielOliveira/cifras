# Projeto Cifras — Instruções para o Claude

## Builds e Testes

**Nunca rode `npm run build`, `ng build`, `npm test` ou qualquer comando de build/teste de forma automática.**

Ao terminar uma alteração, forneça o comando para o usuário rodar:

```
npm run build
```

Aguarde o usuário reportar o resultado antes de continuar.
